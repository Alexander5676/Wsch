# Wsch Portal Prototype

Единое пространство для клиентов, педагогов и администраторов школы. Прототип показывает, как данные из Alfa CRM могут попадать в личные кабинеты и запускать обязательные push-уведомления.

## Что реализовано

- **Клиент:** расписание, история уроков, баланс, остаток оплаченных занятий, домашние задания, материалы, комментарии и голосовые педагога, шкалы прогресса, чат «❤ Служба заботы», новости школы, прикрепление ДЗ и комментария к уроку.
- **Педагог:** расписание, карточки учеников, комментарий после урока, изменение шкал навыков вверх/вниз, прикрепление материалов, ДЗ и голосовых рекомендаций.
- **Администратор:** карточки клиентов, обращения, публикация новостей, расписание, комментарии, список push-уведомлений.
- **Alfa CRM:** мок синхронизации учеников, педагогов, расписания, баланса, остатка уроков и клиентских данных.
- **Push:** кнопка запроса разрешения браузера и генерация напоминаний по ближайшим урокам.

## Запуск

Откройте `index.html` в браузере или поднимите любой статический сервер из корня репозитория.
